BitCompressor Support

Help for BitCompressor on macOS

Need help importing a video, exporting a compressed file, or restoring a Pro purchase? Start with the answers below, or contact us directly.

Contact support

Email bitcompressor@gmail.com, or use the feedback option in BitCompressor. Please include your macOS version, BitCompressor version, the video format, and any error message. A screenshot can help. Only attach media files if you are comfortable sharing them.

Frequently asked questions

How do I add videos?

Use the App's add-media option to select video files or a folder. BitCompressor will list supported videos found in the location you choose. If a file does not appear, check that it is a supported video file and try selecting it directly.

Where are my compressed files saved?

Check the save destination selected in the App. BitCompressor can save beside the source file or to a folder you choose. If you use a custom folder, make sure it still exists and that you have access to it.

What if compression fails?

Check the error shown in the App, confirm that the source file opens normally, and try a different output format or compression setting. Also confirm that the destination has enough free space. If the problem continues, email support with the error text and the settings you used.

How do I restore Pro?

Open the Pro section in BitCompressor and choose Restore Purchases. Make sure you are signed in to the App Store with the Apple Account used for the original purchase. If Pro still does not appear, contact support.

Privacy

BitCompressor processes selected media on your Mac. For details about feedback emails, purchases, and local settings, read our Privacy Policy.
